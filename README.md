# 个人在线简历

GitHub Pages 在线简历，内容基于本人当前中文简历整理。

## 在线访问

- 中文：`https://CookieCocoa.github.io/cv/?lang=zh-CN`
- English：`https://CookieCocoa.github.io/cv/?lang=en-US`

## 技术

纯静态 HTML / CSS / JavaScript，无第三方运行时依赖。

## 文件

- `index.html`：简历页面
- `styles.css`：桌面 / 移动端 / 打印样式
- `app.js`：中英文切换
- `resume.pdf`：PDF 简历

## 本地预览

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080/`。
